常见问题解答 (FAQ)

Q1 如何将 FramerSnap 设置为 Mac 默认看图工具？

只需简单的几步系统设置：

  1. 在访达（Finder）中找到任意一张常见格式图片（如 .jpg 或 .png）。
  2. 右键该图片，点击 “显示简介” (Get Info)。
  3. 在弹出的面板中找到 “打开方式” (Open with)，选择 FramerSnap。
  4. 点击下方的 “全部更改...” (Change All...) 按钮确认即可。之后双击该类型图片都将直接通过 FramerSnap 极速打开！

Q2 FramerSnap 支持哪些图片格式？是否支持相机 RAW？

FramerSnap 原生基于 macOS 底层 CoreGraphics 与 ImageIO 构建，全面支持：

  • 日常常用格式：JPG / JPEG、PNG、WebP、HEIC / HEIF、TIFF、GIF、BMP。
  • 专业相机 RAW 格式：全面兼容 Apple RAW 引擎所支持的 Canon (CR2/CR3)、Nikon (NEF)、Sony (ARW)、Fujifilm (RAF)、Adobe DNG 等。

Q3 为什么经过智能压缩后，图片体积保证不会反向变大？

很多二次压缩算法在遇到网络上已经被高度优化的 JPG 时，会因高频 DCT 重新量化导致体积反而膨胀。FramerSnap 独创了“零反弹自适应降档压缩机制”：系统会在编码后严格校验输出字节与原图大小；若体积未见缩减，会自动拦截并安全保留原图，杜绝任何反向膨胀。

Q4 更换了新 Mac 电脑，如何恢复已购买的 Pro 会员？

只要您在新 Mac 上登录的是购买时相同的 Apple ID：

  1. 在新 Mac 打开 FramerSnap。
  2. 点击工具栏或相框面板右上角的 “Pro” 徽章 打开购买弹窗。
  3. 点击弹窗底部的 “恢复购买” (Restore Purchases)。
  4. 系统将自动通过 StoreKit 2 与 Apple 验证您的授权凭证，瞬间解锁全部 Pro 权益。

Q5 如何取消自动续期的年度订阅？

订阅完全由 Apple ID 统一管理，您可以随时自主取消：

  • 打开 Mac 的 “系统设置” -> 点击顶部的个人 Apple ID -> “媒体与购买项目” -> 点击“订阅”管理。
  • 或者直接打开 App Store，点击左下角头像 -> “账户设置” -> 在“订阅”一栏点击管理并取消续订。

Q6 我的摄影作品会被上传到云端服务器吗？

绝对不会。 FramerSnap 是一款 100% 纯本地离线运行的工具，零云端中转服务器，零数据采集 SDK。所有图片像素解码、相框排版渲染、智能压缩与格式转换全都在您的 Mac 本机完成，您可以随时断开网络运行验证。
